# 数据依据

本文记录容器目录、模拟权重和每日密码来源的依据。资料最后核验日期为 2026-09-03。

## 容器目录

- [《三角洲行动》官方地图工具](https://df.qq.com/cp/a20240729directory/m/index.html)：确认当前烽火地带地图范围和物资点语境。
- [17173：常规容器产出物资类型一览](https://news.17173.com/content/10282025/131243957.shtml)：用于整理常规容器名称与工艺、电子、情报、能源、医疗、工具和家居类别之间的对应关系。
- [腾讯新闻：容器爆率分级](https://news.qq.com/rain/a/20251027A01KIQ00)：用于确认高、中、低相对档位，不作为精确概率来源。
- [三角洲糕手：全容器爆率与出货解析](https://www.wplew.com/p/283.html)：用于交叉检查容器别名、出货类别和特殊容器描述。

不同社区资料对服务器、大武器箱、高级储物箱等容器的档位存在差异。插件采用稳定的四档娱乐配置，并在结果中明确说明“模拟概率，不代表游戏实际掉落”。网上没有找到可复核的官方精确掉落表，因此不把无原始样本的百分比写成游戏事实。

## 每日密码

- 主接口：[18183 每日密码工具](https://db.18183.com/sjzmm/)提供的按日期结构化 JSON；默认地址模板为 `https://db.18183.com/sjzmm/data/daily/{date}.json`
- 当日交叉检查：[星眠 API 每日密码](https://api.xingmian.bbroot.com/API/Delta.php?format=json)与公开攻略页
- 腾讯 AMS 接口形状参考：[每日密码新版接口说明](https://df-api.apifox.cn/327222892e0)

腾讯 AMS 直连接口需要登录 Cookie，参数也不是公开稳定合同，因此插件默认不接入该路径。2026-09-03 核验时，18183 按日期 JSON 返回当天六张地图的完整结果；星眠 API 虽为当天数据，但存在重复项且缺少长弓溪谷，Tmini 仍停留在 2026-09-01，因此二者都不作为默认源。所有第三方结果在运行时仍须通过日期、更新时间、地图集合和密码格式校验，并保留可替换接口配置。

## 更新规则

容器或物品数据更新时：

1. 修改 `source_version`，保留用户可见的版本标识。
2. 检查所有容器的每个非零品质档位都有候选物品。
3. 不依据单次截图、主播体感或无样本文章修改概率。
4. 新增活动容器时单独说明适用赛季和停用条件。
5. 不引入来源不明或授权不清晰的游戏图片与代码。
